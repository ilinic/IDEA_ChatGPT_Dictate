# IDEA ChatGPT Dictate — голосовой ввод для Codex в IntelliJ IDEA

[![Сборка плагина](https://github.com/ilinic/IDEA_ChatGPT_Dictate/actions/workflows/build.yml/badge.svg)](https://github.com/ilinic/IDEA_ChatGPT_Dictate/actions/workflows/build.yml)

**Версия 1.0: голосовая диктовка на нескольких языках прямо в поле Codex с распознаванием OpenAI и исправлением технических терминов по контексту проекта.**

Плагин предназначен для разработчиков, которым удобнее проговаривать задачи, вопросы и описания ошибок голосом. Он распознаёт речь, помогает правильно записать имена Java-классов, методов и библиотек, а затем по выбору **оставляет текст в чате или сразу отправляет сообщение**.

[English README](README.md) · [Готовые сборки](https://github.com/ilinic/IDEA_ChatGPT_Dictate/actions/workflows/build.yml)

## Возможности

- Две настраиваемые клавиши **F1–F12**: первая запускает запись и завершает её со вставкой текста, вторая завершает запись с отправкой сообщения через Enter.
- **Escape** отменяет запись или обработку без вставки и отправки текста.
- Распознавание через `gpt-transcribe` на выбранных языках (14 вариантов) или с автоматическим определением языка.
- Дополнительное исправление распознанного текста выбранной моделью OpenAI.
- Контекст открытого исходного файла: проект, путь к файлу, курсор, Java-класс и метод.
- Необязательное использование последних 2, 4, 8 или 16 сообщений Codex, **только когда точный ID диалога доступен плагину**.
- Единое окно настроек на языке интерфейса IntelliJ IDEA (русский или английский): ключ, горячая клавиша, модель, языки и контекст.
- Статусы записи и обработки отображаются в нижней строке состояния IDE, без всплывающих уведомлений.
- Защита от случайной вставки и отправки: если фокус изменился, готовый текст помещается в буфер обмена без нажатия Enter.

## Установка на Windows

1. Открой [GitHub Actions — Build IntelliJ Plugin](https://github.com/ilinic/IDEA_ChatGPT_Dictate/actions/workflows/build.yml).
2. Выбери последнюю успешную сборку и скачай артефакт `idea-chatgpt-dictate`.
3. Распакуй скачанный архив — **внутри лежит установочный ZIP плагина**.
4. В IntelliJ IDEA открой **Settings → Plugins → ⚙ → Install Plugin from Disk**, укажи ZIP плагина и перезапусти IDEA при необходимости.

Для сборки из исходников нужен JDK 21. В Windows PowerShell:

```powershell
git clone https://github.com/ilinic/IDEA_ChatGPT_Dictate.git
cd IDEA_ChatGPT_Dictate
.\gradlew.bat buildPlugin
```

Файл для установки появится в папке `build/distributions/`. Переменная `JAVA_HOME` должна указывать на корневую папку JDK, а не на `bin`.

## Настройка

Открой **Tools → IDEA ChatGPT Dictate → Настройки…**.

| Поле | Назначение |
| --- | --- |
| **API-ключ OpenAI** | Ключ от OpenAI Platform хранится в Password Safe и отображается точками. Чтобы удалить сохранённый ключ, очисти поле и сохрани настройки. Переменная `OPENAI_API_KEY`, если установлена, остаётся альтернативным источником ключа. |
| **Начать / остановить (вставить)** | Кликни по полю сочетания и нажми F1–F12. Первое нажатие запускает запись, второе завершает её и оставляет текст в композере. |
| **Остановить и отправить** | Кликни по второму полю и назначь другую F-клавишу. Во время записи она запускает распознавание, вставку и отправку через Enter. Delete очищает назначение. |
| **Модель правки текста** | GPT-6 Luna (самая экономичная, по умолчанию), GPT-6.1 Terra, GPT-6.1 Sol или GPT-6 Astra. |
| **Языки распознавания** | Выбери один или несколько языков. По умолчанию — русский и английский. Пустой выбор означает автоопределение. |
| **Использовать контекст Codex, когда доступен** | Галочка включена по умолчанию. История передаётся только при достоверно определённом ID сессии, иначе не передаётся. |
| **Объём истории** | Последние 2, 4, 8 (по умолчанию) или 16 сообщений. |

Модель распознавания речи `gpt-transcribe` используется независимо от выбора модели исправления текста. **ChatGPT Plus не включает использование OpenAI Platform API**: для работы нужен отдельный API-ключ и оплата по тарифам API.

## Использование

1. Открой проект и нужный исходный файл, если хочешь передать модели технический контекст.
2. Поставь курсор в поле ввода чата Codex и нажми **первую** F-клавишу, чтобы начать запись.
3. Нажми **её повторно**, чтобы получить исправленный текст без отправки, **или вторую F-клавишу**, чтобы автоматически отправить распознанное сообщение.
4. Нажми **Escape** во время записи или обработки, чтобы отменить диктовку.

Те же команды доступны в **Tools → IDEA ChatGPT Dictate**. Максимальная продолжительность записи — 120 секунд.

Если во время обработки ты переключился в другое окно, текст будет скопирован в буфер обмена. Верни курсор в чат и нажми `Ctrl+V`.

## Как это работает

1. Java Sound записывает звук в оперативную память как WAV без создания временного аудиофайла.
2. OpenAI `gpt-transcribe` возвращает исходную транскрипцию.
3. Выбранная GPT-модель исправляет ошибки распознавания и терминологию с учётом контекста IDEA и, если доступна, недавней истории Codex, сохраняя язык оригинала.
4. Плагин вставляет исправленный текст в поле ввода; при завершении второй F-клавишей дополнительно нажимает Enter. Если исправление не удалось, сохраняется исходная транскрипция.

## Конфиденциальность

- Запись начинается только по твоему действию, фонового прослушивания нет.
- Для диктовки отправляются аудиозапись и ограниченный контекст: путь проекта, сведения об исходном файле, классе и методе, краткий фрагмент выделенного текста.
- **Весь репозиторий не загружается.** История Codex используется только при включённой настройке и проверенном ID сессии, соответствующей проекту. Переменные `CODEX_THREAD_ID` и `CODEX_SESSION_ID` зачастую доступны только процессу агента Codex, а не IntelliJ; в таком случае история не отправляется. По одной открытой вкладке или рабочему каталогу надёжно определить сессию нельзя.
- API-ключ не публикуется в Git и хранится через механизм IntelliJ Password Safe. Поддерживается переменная окружения `OPENAI_API_KEY`.
- Статусные сообщения всегда видны в нижней строке IntelliJ IDEA. Ошибки и предупреждения дополнительно попадают в журнал событий без всплывающих окон.
- Для запросов исправления текста используется `store: false`. Остальная обработка данных регулируется правилами OpenAI API.

## Совместимость

Плагин написан на Java 21 для IntelliJ Platform с версии **253** (IntelliJ IDEA 2025.3.3). Основной процесс диктовки проверен на Windows в IntelliJ IDEA 2026.2; другие платформы пока отдельно не проверялись.
