# IDEA ChatGPT Dictate — голосовой ввод для Codex в IntelliJ IDEA

[![Сборка плагина](https://github.com/ilinic/IDEA_ChatGPT_Dictate/actions/workflows/build.yml/badge.svg)](https://github.com/ilinic/IDEA_ChatGPT_Dictate/actions/workflows/build.yml)

**Русская голосовая диктовка прямо в поле ввода Codex с распознаванием OpenAI и исправлением технических терминов по контексту проекта.**

Плагин предназначен для разработчиков, которым удобнее проговаривать задачи, вопросы и описания ошибок голосом. Он распознаёт русскую речь, помогает правильно записать имена Java-классов, методов и библиотек, затем вставляет текст в чат **без автоматической отправки сообщения**.

[English README](README.md) · [Готовые сборки](https://github.com/ilinic/IDEA_ChatGPT_Dictate/actions/workflows/build.yml)

## Возможности

- Запись с микрофона по одной настраиваемой клавише **F1–F12**: первое нажатие — старт, второе — стоп.
- Распознавание через `gpt-transcribe`, включая русскую речь с английскими техническими терминами.
- Дополнительное исправление распознанного текста выбранной моделью OpenAI.
- Контекст открытого исходного файла: проект, путь к файлу, курсор, Java-класс и метод.
- Необязательное использование истории **только вручную выбранного** диалога Codex.
- Единое окно настроек: ключ, горячая клавиша, модель и история диалога.
- Защита от случайной вставки в исходный код: если фокус изменился, готовый текст помещается в буфер обмена.

## Установка на Windows

1. Открой [GitHub Actions — Build IntelliJ Plugin](https://github.com/ilinic/IDEA_ChatGPT_Dictate/actions/workflows/build.yml).
2. Выбери последнюю успешную сборку и скачай артефакт `idea-chatgpt-dictate`.
3. Распакуй скачанный архив — **внутри лежит установочный ZIP плагина**.
4. В IntelliJ IDEA открой **Settings → Plugins → ⚙ → Install Plugin from Disk**, укажи ZIP плагина и перезапусти IDEA при необходимости.

Для сборки из исходников нужен JDK 21. В Windows PowerShell:

```powershell
git clone https://github.com/ilinic/IDEA_ChatGPT_Dictate.git
cd IDEA_ChatGPT_Dictate
.\gradlew.bat buildPlugin
```

Файл для установки появится в папке `build/distributions/`. Переменная `JAVA_HOME` должна указывать на корневую папку JDK, а не на `bin`.

## Настройка

Открой **Tools → IDEA ChatGPT Dictate → Настройки…**.

| Поле | Назначение |
| --- | --- |
| **API-ключ OpenAI** | Ключ от OpenAI Platform. Хранится в Password Safe IntelliJ IDEA. Пустое поле не изменяет ранее сохранённый ключ. |
| **Горячая клавиша** | Выбор одной клавиши F1–F12. Если клавиша уже занята в IDE, переназначение потребует подтверждения. |
| **Модель правки текста** | GPT-6 Luna (самая экономичная, по умолчанию), GPT-6.1 Terra, GPT-6.1 Sol или GPT-6 Astra. |
| **Контекст диалога** | Можно выбрать историю конкретной сессии Codex или совсем отключить её использование. |

Модель распознавания речи `gpt-transcribe` используется независимо от выбора модели исправления текста. **ChatGPT Plus не включает использование OpenAI Platform API**: для работы нужен отдельный API-ключ и оплата по тарифам API.

## Использование

1. Открой проект и нужный исходный файл, если хочешь передать модели технический контекст.
2. Поставь курсор в поле ввода чата Codex.
3. Нажми выбранную F-клавишу и продиктуй текст.
4. Нажми её ещё раз: запись остановится, текст будет распознан и исправлен.
5. Проверь результат. Сообщение **не отправляется автоматически**.

Также можно выбрать **Tools → IDEA ChatGPT Dictate → Начать / остановить диктовку**. Максимальная продолжительность записи — 120 секунд.

Если во время обработки ты переключился в другое окно, текст будет скопирован в буфер обмена. Верни курсор в чат и нажми `Ctrl+V`.

## Как это работает

1. Java Sound записывает звук в оперативную память как WAV без создания временного аудиофайла.
2. OpenAI `gpt-transcribe` возвращает исходную транскрипцию.
3. Выбранная GPT-модель исправляет очевидные ошибки распознавания и терминологию с учётом контекста IDEA и выбранного диалога Codex.
4. Плагин вставляет исправленный текст в поле ввода. Если исправление не удалось, сохраняется исходная транскрипция.

## Конфиденциальность

- Запись начинается только по твоему действию, фонового прослушивания нет.
- Для диктовки отправляются аудиозапись и ограниченный контекст: путь проекта, сведения об исходном файле, классе и методе, краткий фрагмент выделенного текста.
- **Весь репозиторий не загружается.** История Codex добавляется только после явного выбора соответствующего диалога.
- API-ключ не публикуется в Git и хранится через механизм IntelliJ Password Safe. Поддерживается переменная окружения `OPENAI_API_KEY`.
- Для запросов исправления текста используется `store: false`. Остальная обработка данных регулируется правилами OpenAI API.

## Совместимость

Плагин написан на Java 21 для IntelliJ Platform с версии **253** (IntelliJ IDEA 2025.3.3). Основной процесс диктовки проверен на Windows в IntelliJ IDEA 2026.2; другие платформы пока отдельно не проверялись.
